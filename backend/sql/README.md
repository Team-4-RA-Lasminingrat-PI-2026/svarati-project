# Database SQL Svarati

Folder ini berisi dump database produksi. Dengan dua file ini, database baru bisa dibangun dari awal.

## Isi folder

| File | Isi |
|---|---|
| `schema.sql` | Struktur 16 tabel, fungsi, trigger, index, dan aturan akses (RLS) |
| `seed.sql` | Data awal: provinsi, kota, topik, entri dokumen, pertanyaan Cek Kondisi, layanan, dan track relaksasi |
| `README.md` | Panduan ini |

## Yang tidak ikut dalam dump

- **`knowledge_chunks`**: dibuat ulang lewat ingestion (`scripts/run_ingestion.py`). Tabel ini besar, dan vektornya bisa dihitung ulang dari dokumen sumber.
- **Data sesi dan chat**: `anonymous_sessions`, `ai_messages`, `ai_message_sources`, `ai_feedback`, `article_likes`, `reinforcement_messages`, `reinforcement_reactions`. Data ini berisi aktivitas pengguna dan dibuat saat aplikasi dipakai.

## Cara membangun database baru

Prasyarat: PostgreSQL 17 atau yang kompatibel (misalnya Supabase), dan `psql` terpasang.

1. Aktifkan extension vector (cukup sekali di database baru):
   ```sql
   CREATE EXTENSION IF NOT EXISTS vector WITH SCHEMA public;
   ```

2. Jalankan struktur:
   ```powershell
   psql "$DB" -v ON_ERROR_STOP=1 -f schema.sql
   ```

3. Jalankan data awal:
   ```powershell
   psql "$DB" -v ON_ERROR_STOP=1 -f seed.sql
   ```

4. Cek jumlah baris (lihat bagian Verifikasi di bawah).

5. Jalankan ingestion untuk membuat `knowledge_chunks`.

## Catatan

- **SQL Editor Supabase tidak bisa menjalankan `seed.sql`** karena file ini memakai `COPY`. Gunakan `psql`.
- **Baris `\restrict` dan `\unrestrict`**: jika `psql` lebih lama dari versi pembuat dump, baris ini menimbulkan error. Hapus kedua baris itu dari file sebelum dijalankan.
- **Baris `CREATE SCHEMA public;`**: akan error di Supabase karena schema sudah ada. Hapus baris ini jika muncul.
- **Kolom identitas `GENERATED ALWAYS`**: jika muncul error `cannot insert a non-DEFAULT value into column`, ubah menjadi `GENERATED BY DEFAULT` di `schema.sql`. Lakukan hanya untuk database test, bukan produksi.
- **Jangan simpan connection string atau password** di file ini atau di repo.
